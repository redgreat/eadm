## 简介

本指南旨在为开发者提供一份全面的实践手册，涵盖从环境搭建、项目启动、功能开发到调试与贡献的完整流程。项目 `eadm` 是一个基于 Erlang 的管理后台系统，支持多数据库、Docker 部署，并集成了用户管理、财务、健康、轨迹回放等模块。通过本指南，开发者可以快速上手并高效参与项目开发。

## 开发环境搭建

### 安装 Erlang

本项目基于 Erlang 27.2.3 构建，建议使用 Docker 镜像或通过官方源安装：

```bash
# 使用 Alpine Linux 安装 Erlang
apk add erlang

# 或使用 kerl 管理多个 Erlang 版本
curl -O https://raw.githubusercontent.com/kerl/kerl/master/kerl
chmod +x kerl
./kerl build 27.2.3 27.2.3
./kerl install 27.2.3 ~/erlang/27.2.3
```

### 安装 Rebar3

Rebar3 是 Erlang 的构建工具，用于编译和发布项目：

```bash
wget https://s3.amazonaws.com/rebar3/rebar3 && chmod +x rebar3
sudo cp rebar3 /usr/local/bin/
```

### 安装 Docker 与 Docker Compose

确保已安装 Docker 和 Docker Compose，用于本地服务部署：

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

## 项目快速启动

### 使用 Docker Compose 启动

项目已提供 `docker-compose.yml`，可一键启动 PostgreSQL 和 `eadm` 服务：

```bash
# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f eadm
```

服务启动后，可通过 `http://localhost:8080` 访问系统。

### 手动构建与运行

若需本地编译运行：

```bash
# 克隆项目
git clone https://github.com/redgreat/eadm.git
cd eadm

# 编译并发布
rebar3 as prod release

# 启动应用
./_build/prod/rel/eadm/bin/eadm start
```

## 新功能开发流程

### 添加新的控制器

1. 在 `src/controllers/` 目录下创建新的 Erlang 文件，如 `eadm_new_controller.erl`。
2. 实现模块并导出处理函数，例如 `index/1`、`search/1`。
3. 在 `eadm_router.erl` 中添加路由规则：

```erlang
{"/new", fun eadm_new_controller:index/1, #{methods => [get]}}
```

- [eadm_router.erl](file://src/eadm_router.erl#L1-L165)

### 添加前端页面

1. 在 `priv/assets/js/` 中创建对应的 JavaScript 文件，如 `new.js`。
2. 在 `priv/assets/css/` 中添加样式文件。
3. 在 HTML 模板中引入脚本和样式。
4. 确保路由与控制器匹配，前端通过 AJAX 调用后端 API。

### 数据库迁移

项目支持多种数据库（PostgreSQL、MySQL、Oracle 等），迁移文件位于 `script/` 目录下：

- `script/postgres/datastruct.sql`：PostgreSQL 表结构
- `script/mysql/DataStruct.sql`：MySQL 表结构
- `script/oracle/DATASTRUCT.sql`：Oracle 表结构

新增表或字段时，需在各数据库脚本中同步更新。

## 调试工具使用

### debug-toolbar.js 使用方法

`debug-toolbar.js` 用于在 iframe 中注入 `<base target="_parent">`，防止页面跳转被限制在 iframe 内：

```javascript
$(document).ready(function() {
    $('iframe#page').contents().find('head').append('<base target="_parent">');
});
```

该脚本在页面加载时自动执行，确保所有链接在父窗口打开。

## 日志查看与调试

### 使用 Lager 查看日志

项目使用 `lager` 作为日志框架，日志输出到 `log/` 目录。关键日志调用包括：

- `lager:info("EADM 启动成功，访问地址：http://127.0.0.1:8080")`
- `lager:error("用户查询失败：~p~n", [Error])`

可通过以下命令查看实时日志：

```bash
tail -f log/erlang.log.*
```

### 日志记录到数据库

部分关键操作（如定时任务）会同时记录到数据库 `sys_cronlog` 表中，便于追踪：

```erlang
lager:info("Crontab Task [~s]: ~s", [JobId, Message]),
eadm_pgpool:equery(pool_pg, "insert into sys_cronlog(cronid, cronlog) values($1, $2);", [JobId, MessageBin])
```

## 新贡献者入门路线图

1. **环境准备**：安装 Erlang、Rebar3、Docker。
2. **项目启动**：使用 `docker-compose up` 启动服务，访问 Web 界面。
3. **代码浏览**：阅读 `eadm_router.erl` 了解路由结构，查看 `controllers/` 理解 MVC 模式。
4. **功能开发**：
   - 选择一个 `⭐️ ❎` 标记的任务。
   - 添加控制器、前端页面和数据库变更。
   - 提交 PR 并附上测试说明。
5. **调试与日志**：使用 `lager` 查看日志，利用 `debug-toolbar.js` 辅助前端调试。
6. **持续贡献**：参与 `TODO.TXT` 中的高优任务，逐步深入核心模块。

通过本路线图，新贡献者可系统性地融入项目开发，快速产出有效代码。
